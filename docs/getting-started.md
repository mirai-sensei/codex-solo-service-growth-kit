# Getting Started

This guide is for maintainers and solo operators who want to try the kit without adopting every template at once.

## 15-Minute First Run

1. Pick one service workflow.
   Use a real workflow such as a free consultation, a discovery call, a paid reading, a coaching package, or a weekly content loop.

2. Copy only the templates you need.
   Start with `templates/funnel-map.md`, `templates/daily-kpi.md`, and `templates/weekly-review.md`.

3. Fill in the current state.
   Keep the first version rough. The goal is to make the handoff visible, not perfect.

4. Ask Codex for one improvement.
   Use `templates/codex-maintenance-prompt.md` and ask for a single low-risk change.

5. Record what changed.
   Update the weekly review so the next pass starts from evidence instead of memory.

## What Good Usage Looks Like

- One workflow is described clearly enough for another person to understand.
- The free entry point, paid offer, follow-up step, and owner are visible.
- Metrics are simple and repeatable.
- Suggested changes are small enough to review.
- No customer data, secrets, credentials, or payment records are copied into the templates.

## When To Open An Issue

Open an issue when a repeated workflow appears more than once and does not fit an existing template. Good issue requests include:

- The repeated workflow.
- Who would use the template.
- The current workaround.
- The minimum sections the template needs.
- Any safety boundaries, such as data that must not be stored.
