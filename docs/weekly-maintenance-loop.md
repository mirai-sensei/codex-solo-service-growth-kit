# Weekly Maintenance Loop

Use this loop once a week to keep growth work focused and reviewable.

## 1. Collect Inputs

- Latest `templates/daily-kpi.md` entries.
- Current `templates/funnel-map.md`.
- Any notes from customer conversations, support messages, or sales calls.
- Current content plan or `templates/short-video-brief.md`.

Do not include private customer details, payment logs, secrets, or production credentials.

## 2. Ask for One Bottleneck

Use Codex to identify the single weakest step:

```text
Read the current funnel map, daily KPI entries, and weekly review notes.
Find the one bottleneck that is most likely limiting revenue.
Return one recommended improvement, why it matters, and how to verify it next week.
Do not suggest production setting changes, payment changes, or customer-data handling changes.
```

## 3. Make One Small Change

Good weekly changes are narrow:

- Clarify one CTA.
- Shorten one form.
- Improve one offer explanation.
- Add one missing example.
- Rewrite one content hook.
- Update one follow-up message draft.

## 4. Review the Result

At the next weekly review, compare the same KPI steps before deciding the next change.

The goal is not to do everything. The goal is to make improvement repeatable.
