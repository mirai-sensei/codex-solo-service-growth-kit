# Roadmap

This project is intentionally small. The goal is to improve the usefulness of the template kit through practical, reviewable updates.

## Near Term

- Add more filled-in examples for free-to-paid funnels.
- Improve the daily KPI template with clearer definitions and examples.
- Add a newsletter funnel example.
- Add a template scoring checklist for reviewing new operating templates.
- Improve validation output readability for first-time contributors.

## Later

- Add more validation checks for required template sections.
- Add examples for newsletter, short video, and consultation follow-up workflows.
- Add a small maintainer playbook for reviewing pull requests with Codex.

## Open Issues To Tackle First

- Add more sample funnel maps.
- Add a creator content calendar template.
- Improve validation script coverage.
- Add newsletter funnel example.
- Add template scoring checklist.
- Improve validation output readability.

## Non-Goals

- This is not a CRM.
- This is not a payment system.
- This is not a marketing automation platform.
- This project should not store customer data, secrets, or private business records.
