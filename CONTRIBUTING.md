# Contributing

Thanks for helping improve this kit.

## Good Contributions

- New templates that help solo service businesses operate more repeatably.
- Clear examples with fake data only.
- Better Codex prompts for review, triage, documentation, and maintenance.
- Small scripts that validate templates or check for missing sections.

## Before Opening a Pull Request

1. Do not include secrets, private URLs, customer data, payment data, or real consultation records.
2. Keep examples generic and fictional.
3. Run:

```bash
python scripts/validate_templates.py
```

4. Explain what workflow your change improves.

## Style

- Prefer plain Markdown.
- Keep templates easy for non-engineers to copy.
- Use concrete fields over long explanations.
- Make the next action obvious.
